# 2026-09-11 개발 기록

## 🚀 프로젝트 시작

공모전 프로젝트 **우심운까**의 프론트엔드 작업을 시작했다.

웹 실습으로 HTML, CSS, JavaScript를 배우기 시작한 단계에서
실제 프로젝트의 화면 구현을 맡게 되었다.

처음에는 완성된 구조를 알고 시작한 것이 아니라,

> 프론트엔드로 웹페이지를 만들어야 하는데 어떻게 해야 하지?

라는 상태에서 하나씩 화면을 만들어 보기 시작했다.

---

## 👩‍💻 담당 영역

팀 프로젝트에서 나는 다음 영역을 담당했다.

```text
PAGE1
M4
```

프로젝트 전체를 한 번에 구현하기보다
내가 맡은 PAGE1부터 화면을 만들어 가기로 했다.

---

## 🧱 첫 화면 만들기

처음 만든 `landing.html`은 아주 단순했다.

```html
<body>
    <h1>🔥 지금 대한민국은 운동 중입니다.</h1>
</body>
```

처음부터 복잡한 기능을 구현하기보다
HTML 파일이 실제로 브라우저에서 실행되는 것부터 확인했다.

---

## 🛠 첫 번째 시행착오

VS Code에서 HTML을 실행하려고 했는데
작업 영역 신뢰와 관련된 메시지가 나오면서 미리보기가 제대로 되지 않았다.

이 과정에서 처음으로 다음 설정도 확인했다.

```text
Workspace Trust
작업 영역 신뢰
```

프로젝트 첫날부터 단순히 코드를 작성하는 것뿐 아니라
개발 환경에서 발생하는 문제도 하나씩 해결하기 시작했다.

---

## 🌱 시작 당시의 흐름

```text
HTML / CSS / JavaScript 기초 학습
↓
공모전 프로젝트 참여
↓
PAGE1 / M4 담당
↓
landing.html 작성
↓
브라우저에서 첫 화면 실행
```

이후 이 PAGE1을 기반으로 기능과 디자인을 계속 확장하게 되었다.

---

## 📌 기록

이 시점에서는 완성된 프론트엔드 구조를 알고 시작한 것이 아니었다.

작은 화면 하나를 직접 만들고 실행해 보면서
필요한 기능을 하나씩 추가하는 방식으로 프로젝트를 진행하기 시작했다.

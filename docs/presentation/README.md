# Presentation Material Development

우심운까 프로젝트 발표자료의 제작 및 수정 과정을 기록한 아카이브입니다.

발표자료는 단순한 시각 디자인 작업이 아니라,
프로젝트 구조와 데이터 파이프라인을 이해한 뒤
발표자가 실제로 설명하기 쉬운 형태로 내용을 재구성하는 과정으로 진행했습니다.

---

## Revision History

### 1. Initial Version

**우심운까_발표자료_전체.pptx**

프로젝트 소개, 서비스 목표, 운동 데이터 활용,
추천 점수, 데이터 파이프라인 등
전체 발표 흐름을 구성한 초기 버전입니다.

---

### 2. Revised Version

**우심운까_발표자료_전체-수정본.pptx**

초기 버전을 바탕으로 발표 흐름과 슬라이드 순서를 조정하고,
서비스 설명과 데이터 관련 내용을 보완했습니다.

발표자가 실제 발표에서 설명하기 쉽도록
내용의 순서와 표현을 반복적으로 수정했습니다.

---

### 3. Final Expected Version

**우심운까_발표자료_최종예상.pptx**

수정 과정에서 데이터 파이프라인의 전체 구조를 다시 정리하고,
발표자의 요청을 반영하여 내용을 추가·수정한 최종 예상 버전입니다.

특히 다음 내용을 보완했습니다.

- 데이터 파이프라인 전체 개념 정리
- 데이터 수집 흐름 정리
- 예외 처리 및 복구 과정 정리
- RAW / PROCESSED 데이터 구조 정리
- 데이터 품질 검사(DQ) 개념 정리
- 스케줄링 및 자동화 흐름 정리
- 로그 및 모니터링 구조 정리
- 추천 데이터와 서비스 기능의 연결 관계 정리
- 발표자 요청에 따른 슬라이드 순서 및 내용 수정
- 기술적인 내용을 발표용 문장과 도식으로 재구성
